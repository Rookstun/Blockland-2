# City environment

city.bp = environment preset of the city build (saved from world `gta`, 2026-10-26). Server copy: `data/Saved/Presets/Environment/city.bp`.
Load: `br.Server.Environment.LoadPreset city`. Save changes: `br.Server.Environment.SavePreset city`, then scp it back here.
The game rejects preset names with `/`, so presets cannot live in a server subfolder; this folder is the city one.
